===============================================================================
                       CLOUDPILOT - DEVOPS WORKSPACE
                             RUN & DEV COMMANDS
===============================================================================

-------------------------------------------------------------------------------
1. RUNNING THE BACKEND SERVICES MANUALLY (STANDALONE PYTHON)
-------------------------------------------------------------------------------
# Auth Service (Port 8000):
cd backend/auth-service
py -m uvicorn app.main:app --reload --port 8000

# Cloud Service (Port 8001):
cd backend/cloud-service
py -m uvicorn app.main:app --reload --port 8001

-------------------------------------------------------------------------------
2. STARTING VIA DOCKER COMPOSE (RECOMMENDED CONTAINER MODE)
-------------------------------------------------------------------------------
# Start all microservices (Redis, Auth Service, Cloud Service) in detached mode:
docker compose up -d

# Build and start containers:
docker compose up --build -d

# View live container status:
docker compose ps

# View live container logs:
docker compose logs -f cloud-service

-------------------------------------------------------------------------------
3. STOPPING THE PLATFORM
-------------------------------------------------------------------------------
# Stop all running containers:
docker compose stop

# Stop and remove containers and network:
docker compose down

-------------------------------------------------------------------------------
4. AUTOMATED REGRESSION TESTING (PHASE 4A)
-------------------------------------------------------------------------------
# Target isolated test database (zero impact on CloudPilot dev db):
# TEST_DATABASE_URL=postgresql://postgres:postgres@localhost:5432/cloudpilot_test

# Run entire test suite across all services with coverage:
python run_tests.py

# Run Auth & Workspace Service tests only:
pytest backend/auth-service/tests -v

# Run Cloud Service tests only:
pytest backend/cloud-service/tests -v

# Measure coverage for Auth Service:
pytest backend/auth-service/tests --cov=app --cov-report=term-missing

# Measure coverage for Cloud Service:
pytest backend/cloud-service/tests --cov=app --cov-report=term-missing

# Manual Acceptance Checklist:
# Refer to: backend/tests/manual_acceptance_checklist.md
